Структура

Раздел крестиком удаляется только после вопроса. Папку и файл, которые только что создали, можно убрать крестиком без вопроса в первые 5 секунд. Потом тоже спросит.

+ раздел создаёт верхнюю папку, например data. + папка создаёт папку внутри этой строки. + файл создаёт dart-файл в ней. код открывает текст файла.

При генерации расширение спросит имя фичи. Если ввести pay_login:

  • в имени папки и файла NAME остаётся как ввели: NAME_page.dart станет pay_login_page.dart
  • в коде файла NAME становится именем класса: class NAMEPage станет class PayLoginPage
  • LOWER_CASE в коде — pay_login, для part и путей
  • funcCase в коде — payLogin, для имени функции
